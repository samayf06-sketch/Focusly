## 2. Tasks to give each tester (do not explain the app first)

1. Create an account.
2. Add an assignment that is due in 3 days.
3. Find which task the app says to do first, and tell me why you think it says that.
4. Mark a task as done.
5. Find everything due next Friday (try the calendar or search).
6. Try to add a task without a title (what happens?).

Write down: where they hesitated, what they clicked by mistake, what confused them. Stay silent and watch.

## 3. Questions to ask afterwards

- What problem does this app solve for you? Would you actually use it? Why / why not?
- What was confusing or slow?
- What is missing?
- Rate it 1-5 for: easy to use, looks good, useful.
